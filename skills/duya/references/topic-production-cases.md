# 选题生产的修订案例与反例

本文件用于判断训练，按需要读对应案例；不要把任何案例的句式当必用模板。来源见 [创作修订资料](../knowledge/SOURCES.md#source-topic-process)。第一例源于用户授权的文案修订；后续为明确标注的迁移教学例，无发布效果数据。私有完整对话不随包分发。

## 案例一：权责利为什么越改越有冲突，却越来越偏

### 原始材料与后来明确的选择

原稿讨论：老板在一线就能推进，不在时业务卡住；业务骨干未必能独立承担一条业务；要选择、培养负责人，并配置权责利；老板托公司，负责人托业务。投流任务中“成本是40，下一步怎么办”是作者自述案例，原文没有明确40的单位。

最初用户要求增强传播、共鸣、扩大人群，之后又说“讲清权责利模型”。这些材料足以识别“让业务有人承接”的目的，但尚不足以断言用户只接受“筛选方法”一种主交付。模型解释与选人方法之间存在值得用小样澄清的分歧。

后来用户明确：知识类，教怎样筛选合格负责人，解决老板不在一线团队仍能处理问题；核心是相互托举。这才成为后续必须执行的具体选择。

### 逐步失准发生在哪里

1. 第一轮将核心选成“老板嫌员工不主动，员工嫌老板不放权”。它能形成关系冲突，但原稿未确认该案例是由不放权引起。
2. 扩展人群进一步变成“做不了主却要背锅、事情做成了没好处”。同一模型仍在，观众等待的答案已转为职场分配。
3. 用户说太短，就把这个方向展开成长稿；长度反馈被当作沿用整个方向的理由。
4. 用户说开头不够强，就给更多、更尖锐的句子，没有回看内容任务。
5. 用户明确要教筛选方法后，核心、材料和候选才重新对齐。

### 容易漏掉的失败：正确候选已经出现，却没被选中

历史一轮提供18个开头。其中已有“招了负责人，本想轻松，却更忙”与“投流成本40后等下一步”这类靠近原始问题的方向，推荐的却是双方吃亏、甩锅、信任还是挨骂。下一轮也出现“招了负责人，结果你得对他负责”，但推荐仍偏向利益博弈。

因此不能只补“多生成几条”。需要改的是推荐标准：首先对准原任务和观众应得的收获，然后在成立的候选里比较表达力量。

| 候选 | 引发的期待 | 适合的正文 | 在已确定筛人任务中的选择 |
|---|---|---|---|
| 分钱按员工，担责按老板 | 讨论利益是否合理 | 职场立场或配置原则 | 不作为主入口，避免换交付 |
| 提拔了最能干的人，为何自己反而更累 | 理解为何选错/怎样判断 | 个人执行与业务负责的区别、筛选办法 | 适合，反差就是教学对象 |
| 负责人必须具备三种能力 | 获取能力目录 | 方法清单 | 对题但偏平，可进一步具体化 |

### 最后有效的结构变化

用户选择了“你提拔了最能干的人，为什么自己反而更累了？”后，全文形成：能力差异 → 看行为 → 怎么通过追问和真实任务观察 → 选好以后配置权责利 → 相互托举。

重要材料的职责变得清楚：

- “提拔后反而更累”提供值得解释的处境与反差。
- 投流案例让“遇到问题等指令”变得具体。
- 拆路径、处理卡点、跟进结果把抽象能力变成观察对象。
- 追问真实项目、小范围任务让观众知道怎样观察与验证。
- 权责利说明选好人以后，还要给他怎样的工作条件。
- 相互托举概括想形成的组织关系。

上述组织与招聘建议是本案例的实践方法，不声称已验证预测准确性。满意稿未经实际试读与传播测试，不能从用户满意推出完播、分享或获客提升。

### 如果重来，怎样更早帮助用户

先提取并说明：“你希望让业务有人接住；权责利可以作为主模型讲，也可以用来辅助教选人和用人。两种写法看完的收获不同。”各给一句开头和后续教什么，并推荐更符合其原始业务问题的方向。用户确认后再展开。

不是让用户先成为文案专家，而是让他看见容易判断的成品差异。不需要每次写作都先问，不把这次六分钟、三个标准、双角色设为通用规则。

## 案例二：专业术语能换入口，交付不能跟着漂移

以下是装修报价的教学例，不是客户真实案例。

输入：想让第一次装修的人学会比较两份报价，已知清单中包含项目范围、计量口径和暂未确定的项目。作者主张先把比较范围对齐，不能只看总价。

偏题入口：“装修行业有多少见不得人的套路？”它会让人期待曝光故事；若正文只有报价比较方法，就接不住。

平淡入口：“装修报价的比较方法。”意思正确，但观众没有看见为何现在需要。

更匹配的入口：“两份报价差了三万，你现在还不能判断哪份更便宜。”这里“三万”只能在用户材料已有此差额时使用；没提供就改“两份报价总价差不少”。正文需说明总价差异怎样来自范围、数量或待定项目，并教用户对齐比较。不能顺势断言低价必有坑。

可获得的知识：拿出同一个项目核对包含什么、怎样计量、哪些仍待定，再决定能否直接比总价。材料支持到哪就讲到哪，不编行业统一规则。

迁移经验：把“比较口径”变成用户熟悉的钱和选择问题，放大相关性，同时保留原方法的判断任务。

## 案例三：有直观演示时，不强行寻找人际矛盾

以下是收纳演示教学例。

输入：同一个抽屉重新分区的前后素材，用户只要字幕，展示如何让常用工具容易拿到。可用观看理由是从混乱到好取、每个分区为何放在此处、手如何取放。

不适合：“家里为什么总有一个人把所有事情搞砸？”这新增了无事实支持的家庭矛盾，也不帮助观众看懂分区。

可用：“东西没减少，为什么现在一伸手就找得到？”只有实际素材支持“数量相同”才这样说。字幕随后说明常用程度、取放动作和实际位置；不需要强塞某个心理学理论。

迁移经验：传播来自可见差异与实用收获；知识、演示可共同完成任务，不必把所有视频写成观点争论。

## 案例四：只改开头与方向含糊，处理不同

明确请求：“正文就是教新手比较报价，只改前两句。”直接给能接住比较方法的开头，不重问客户是谁、不展开全稿。

含糊请求：“我想讲定价心理学，做得吸引人一点，长一点。”如果现有材料不足以区分面向商家教定价，还是面向顾客解释选择心理，就给两个有正文交付差异的小样及推荐，让用户判断。不要先写两千字，再让用户发现人物和任务全错。

迁移经验：主动确认服务于解决真实歧义；不是把创作任务转换成固定问卷或层层审批。
