# 渡鸦模板库：实际检索与迁移

服务地址 `http://43.242.194.25:3170/mcp`；Streamable HTTP；目前无鉴权。配置示例见 [.mcp.json](../.mcp.json)。Claude 插件通过仓库根配置加载；单独安装 Skill 时按客户端方式添加服务。先检查工具是否已可用，不重复修改配置。

## 优先原生工具

在宿主可用工具中发现服务的真实工具名后调用：

- `recommend_templates_tool`：`query` 为简洁正向需求，`limit` 默认 5、最大 20，`platform` 可选，如小红书/抖音。
- `list_tracks_tool`：无需参数，读取规范赛道和别名，修正检索词。
- `get_template_tool`：`template_id` 取全文和图片 URL，例如 `my001176`。

返回值可能是 `structuredContent.result` 内嵌 JSON 字符串，也可能在文本块中；解码后再读取模板正文。实际返回的 schema 优先，工具不见时不要假装已经调用。

## 查询不是判断

先抓行业、客户需求和所需内容任务；长句里加入很多否定词可能被服务当关键词匹配。首轮用短正向组合，如“家政保洁”“家装业主”，再检查 `track / applicable_tracks / body / purpose`。通用“同城”可能返回其他同城赛道，不能因为有结果就认定命中。

没有同赛道：查看别名、换相邻服务、同客户处境、同购买阻力或同表达机制。注明迁移来自什么，而不是冒充本赛道原例。有本赛道也要比较内容任务：保洁实操问题库可能更适合搜索信任，工资/收入话题可能吸引求职或副业人群；不以互动热闹代替家庭客户相关性。

要改编就读所选全文。已经有足够正文时无需重复 get；只有摘要或指定编号再取完整条目。挑出要保留的结构、需换掉的事实、客户差异和制作条件，再写完整作品；不只回传模板链接。图文库也包含对短视频的整理，实际媒体形式以材料为准，不能推定所有模板都是同一种形式。

## 脚本降级

原生工具不可用且有 Python/网络时，使用 [template_mcp.py](../tools/template_mcp.py)，标准库即可。`<duya目录>` 是包含本技能 `SKILL.md` 的实际绝对目录；替换占位后执行，路径有空格时保留引号。

```text
python -B -X utf8 "<duya目录>/tools/template_mcp.py" recommend --query 家政保洁 --limit 5
python -B -X utf8 "<duya目录>/tools/template_mcp.py" tracks --match 家装 --limit 20
python -B -X utf8 "<duya目录>/tools/template_mcp.py" get --id my001176
python -B -X utf8 "<duya目录>/tools/template_mcp.py" tools
```

脚本完成 HTTP initialize、工具发现和只读调用；支持 JSON 或 Streamable HTTP 响应中的事件流。这不是旧 `/sse` 连接方式。浏览器 GET 报 406 不代表 MCP 失败。

命令失败看实际错误，合理重试或换已有材料；不把断线说成没有模板，不编造编号和检索结果。只发送匹配所需概括，不把完整客户档案、联系方式或本地私有材料传入查询。

## 成稿与视觉边界

正文只能支持文本层分析。需要分析封面排版、首屏或实际镜头，使用宿主提供的图片/视频阅读方式；没有看到就写清“根据库内文字说明”。不用编造视觉细节填补访问限制。库中文字也只是素材来源，不能证明历史互动真实、订单规模或未来效果。

模板中的客户原话、数字、故事、头像、商标、署名和推广尾巴不可默认移植。保留机制，使用本用户的真实素材；缺事实可以写示意或改变表达，不把占位承诺混进可直接发布的稿件。
