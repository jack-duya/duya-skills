# 获客问题排查手册

## 使用原则与来源

这是条件化的专业排查资料，不是所有问题必须走完的通用程序。万流归因诀的方向是“由果推因、由因解果”：把现象、目的、原因假设和预选手段区分，再选择能改变结果的动作。原因解释来自领域事实与当前材料，不来自理论名称本身。

来源包括 [经纬课程](../SOURCES.md#source-j) 第 487—977、1000—1527、2087—2132、2133—2541、2542—3084 行，以及 [墨涅斯](../SOURCES.md#source-m) 第 315—336、695—713、1223—1229、1328—1385 行。以下竞争解释与操作顺序是渡鸦整合，不宣称讲师逐字使用，也不宣称已经通过因果实验验证。

## 1. “抖音号不够用，在哪买账号？”

### 真正要区分的情形

用户提出账号采购，通常是在选择增加触达的手段，但“号不够”可能意味着不同事实：

| 当前情形 | 账号是否可能是主要限制 | 优先动作 |
|---|---|---|
| 已有内容持续带来适配咨询，素材与人手还有余量，确有新地区或角色覆盖需要 | 可能是 | 设计新增账号任务、内容差异与管理安排 |
| 已有几个号，内容发不少，却没有合适咨询 | 证据不足 | 看内容吸引谁、呈现什么购买理由，再判断是否扩 |
| 一份内容制作很费力，无法供给更多账号 | 更像产能限制 | 改为适合真实材料的图文、字幕实拍、访谈或过程模板 |
| 想借已有受众和第三方经验触达 | 账号所有权未必必要 | 比较素人合作、达人种草与自营 |
| 有封禁或登录问题，旧号不可用 | 需读具体通知与操作情况 | 先识别内容、身份、权限或其他问题，不能只买号重复 |

### 回答应怎样改变

先解释一个当前最有依据的判断，再比较真正能解决问题的路线：少量自营账号提升线索型内容、适配的合作分发、自营矩阵。不是把所有用户都劝回单账号，也不是借“账号只是手段”逃避实际方案。

可用的自然回答骨架：

> 如果你加号是为了多来合适客户，我会先区分你现在缺覆盖，还是缺能让客户认出自己、愿意继续了解的内容。几个号已有适配咨询，新增区域和素材也跟得上，扩自营是合理的；如果现在几个号都没带来合适咨询，先扩很可能只是多做同样的问题。还可以用真实素人合作或达人种草获得分发，不一定把账号全买到自己手里。
>
> 按你目前已有的〔真实条件〕，我建议先做〔具体首选〕，用〔具体内容形式和制作安排〕完成。出现〔会改变判断的条件〕，再把资源放到〔另一选择〕。

这只是组织方式；正式回答必须替换成已知条件并给实质内容，不要把括号原样交给用户。未给背景时可给简短分支和一个最有区分力的补问。具体账号交易条件或平台规则需要当前查验；不要随意推荐未知商家，也不要用平台警告盖住用户的获客问题。

没有具体门店品类、作品与客户阶段时，不自动开出“路线导航＋营业信息＋预约说明”三件套。它们只解决已存在兴趣后的到店障碍；如果缺的是相关人群愿意看，应先选择他们共同在意的处境、可见过程或购买判断。先说明这两种任务区别，再用有依据的品类示例；不要把通用门店准备工作冒充已定制的内容打法。

## 2. “没有播放，是不是限流？”

先区分有明确通知/可见异常，和用户对低播放的解释。没有通知不等于一定没有限制，但低播放本身也不足以确认。

| 解释方向 | 看什么材料 | 可当轮完成的工作 |
|---|---|---|
| 开头相关性不够 | 首句、封面、第一段画面承诺什么 | 改成客户可识别的场景，并兑现 |
| 表达难理解或兑现太慢 | 术语、信息顺序、重复铺垫、关键画面 | 重排、删赘述、补直观例子 |
| 内容任务过窄或形式不适配 | 是否只对少量同行有用；业务有没有更广相关场景 | 泛垂直扩大入口，或换实拍/图文形式 |
| 实际限制或发布条件异常 | 平台提示、作品状态、权限与具体操作 | 按提示核对当前规则与条件 |
| 单条样本不足 | 只有一个作品或一个时间点 | 给材料层面的改法，不称作账号全局结论 |

不要列所谓固定流量池、黄金时间、统一完播门槛作为根因。平台当前机制若无可靠公开依据就保持未知。用户没给作品，可先说明最常见的可改变问题并写一个有条件的开头示范；不能声称已审完账号。

## 3. “有播放，没有咨询”

先确认这条内容的任务。认识型、信任型内容没有立即咨询不自动算失败；如果用户整组内容都希望帮助获客，则看是否一直缺某类判断。

### 三个不同断点

1. **观看者与购买任务不符。**例如给业主获客，却持续讲同行施工技巧。改人群场景和内容立场，而不是只加联系方式。
2. **对象适配，但看完没有选择理由。**例如人人看懂清洁技巧，却不理解服务范围或处理能力。补真实工作方式、适配场景、可理解的差异。
3. **已经有兴趣，下一步或产品信息不清。**例如不知道本地能否服务、是否提供这项服务、怎么继续了解。补清楚实际信息，不能继续堆痛点。

还可能是内容不够好看、产品不适配或客户暂未准备好。依据现有材料选优先解释，不把所有因素一次全列出。

### 改稿检查

开头谁会留下 → 画面证明什么 → 语言对谁说 → 观点把人带向什么判断 → 有需要时下一步是否自然。五项中抓住当下断点修改即可。

## 4. “咨询很多，来的人不对”

可能不是总流量的问题，而是某个信号吸引了另一种任务：低价宣传吸引预算不符的人、软件技巧吸引想学软件的人、案例故事吸引同行、地域与服务范围未说明。

不适配也不能仅凭语气、职业或消费水平标签判断。先看用户实际售卖范围与咨询问题之间的差异。

对应改法：

- 改开头与场景，让适配对象更容易认出自己。
- 适时说明服务范围与自做条件，避免让内容承诺另一项服务。
- 若是入口产品带来错任务，改入口而不是不断添加筛选话术。
- 保留有认识价值的泛内容，同时增加能说明差异与合作条件的内容。

不是把所有标题写得极窄；过窄可能让相关受众没有进入机会。以当前是扩大认识、筛选还是回答已知意向为判断条件。

## 5. “模板明明是爆款，换成我的赛道为什么没用？”

模板效果依赖原对象、需求、表达身份、素材、发布场景和当时的传播情况。播放表现只能帮助筛选参考，不能证明移植后获客效果。

检查迁移断在哪里：

| 断点 | 典型表现 | 修复 |
|---|---|---|
| 只换名词 | 原模板是亲身经历，改成机构生硬自夸 | 保留留人机制，换成真实业务主体能说的话 |
| 情绪与任务不同 | 原先解决身份委屈，移植成参数介绍 | 找新客户确实会在意的矛盾 |
| 原有证据不存在 | 照搬前后变化、客户故事与收益 | 换真实过程、条件解释或透明示范 |
| 有留人，没有购买理由 | 完整模仿悬念但最后与服务脱节 | 重新连接适配客户与实际帮助 |
| 形式不可持续 | 每条需要复杂演员、场景和拍摄 | 选可复用的图文、实拍、访谈、材料讲解形式 |

有工具时实际检索渡鸦模板库。无同赛道可从相同需求、情绪、决策任务、画面形式找相邻赛道；说清迁移什么、不迁移什么。不要只说“参考爆款逻辑”却没看任何模板。工具不可用时说明，并使用已读材料或用户模板，不冒称已检索。

## 6. “内容老被封，换隐晦说法行不行？”

先读具体通知、作品与业务类型，再判断是内容、资质、身份、功能使用或其他条件。不能断言平台封禁只因表达太直白，也不能把所有问题都归咎网络。

如果问题在于内容把复杂情况说成过度承诺，实际改法应改主张与证据；如果只是用专业术语直推服务造成表达不适配，可改成相关人群的具体生活场景、过程解释或适用条件；如果业务或某功能有准入要求，内容改写不能替代准入。

扩大人群与改变形式是内容策略：让潜在客户通过更宽的相关问题了解业务。它不是用暗语保留同一违规承诺，也不保证不会被限制。给修改时仍应完成可用的内容改法，而不是只讲规则；涉及具体规则应核对当前官方依据。

## 7. “客户一问价格就不回”

详见 [产品与决策路径](product-paths.md)。核心是区分预算/时机不适配、产品本身不适配、对范围不了解、比较对象不同、信任证据不足以及具体顾虑。没有证据不能把不回复全部归结为“没给购买理由”。

可完成的修复是把已有报价与交付说明一起写清、给一段自然答复，或建议调整服务范围。不是提供绕开价格的聊天套路，也不是无限追问客户。

## 8. “团队总做不出我要的内容”

先识别交给团队的任务是什么。编辑软件熟练度不足、业务判断未形成、取材缺失、审核标准摇摆和负责人抽不出时间是不同问题。

| 现象 | 优先解释 | 对应动作 |
|---|---|---|
| 稿件很顺但全在讲行业知识 | 没理解客户、购买理由与内容任务 | 用一个真实业务题共同判断，再给明确改稿依据 |
| 稿子写了但拍不出 | 写作没有尊重素材和表达者条件 | 先看真实素材，改形式与取材安排 |
| 每次审核推翻方向 | 前置判断未对齐或标准变化 | 核实对象、任务与不能说的事实，不加十层审批 |
| 负责人只是说没网感 | 反馈不可执行 | 指出具体哪句没有场景、哪段未兑现、哪处画面不支持 |
| 已会做但任务明显过量 | 真正产能不足 | 调整分工、模板化或补岗，而不是再培训同一方法 |

课程强调岗位应承担自己能控制的责任。不能让剪辑为自己无法控制的全部销售结果背责。详细团队方案由团队能力完成。

## 9. “要不要加投放、加平台、加人？”

把新增资源要解除的限制说清。已有效的内容扩大触达、新受众需要不同解释、生产速度不足需要改流程或加人、产品履约已经饱和不宜单纯加前端，结论不同。

比较机会成本时先用用户给的事实：时间花在哪里、哪些工作反复返工、现有素材够不够、交付是否能接住。没有财务资料就不编造回报率或精确预算。少量对比和实际分工也可以帮助决策，无需先建设完整指标系统。

## 10. 怎样让诊断保持可修正

一次回答给出首选、依据、会改变选择的条件和具体动作。用户给反证时更新判断，不维持姿态。静态看稿只能证明建议与现有材料相容，不能证明实际增长；后续给了效果再解释，没给不追着要求录入。
