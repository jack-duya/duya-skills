# 知识来源与使用说明

本公开包包含整理后的 23 篇业务知识、方法、适用条件与示例。原始课程全文、原始课件图、本地业务档案及开发机器路径不随公开包发布。正文中的来源行号保留研究时的版本定位，不能当成此页行号。

知识已独立展开，普通使用不需要先取得课程原文。需要审查原句、原图或具体版本时，应读取用户实际提供的材料，或访问以下可公开来源；不可假装已经看到未附材料。

## 对标与改写说明

主页与新手教程的栏目组织参考 [dontbesilent2025/dbskill](https://github.com/dontbesilent2025/dbskill)。其作者为 dontbesilent，项目采用 [CC BY-NC 4.0](https://github.com/dontbesilent2025/dbskill/blob/main/LICENSE)。渡鸦重新编写了品牌介绍、实际能力、使用案例、教程和图示；部分内容方法在保留来源的基础上重组，使用对象转为商业与线索获客。不存在官方合作或作者背书的声明。

经纬课程、网感训练营与旧墨鸦材料用于方法研究，课程主张、作者自述、教学示例与本版新增建议分别处理。来源不在公开网络或未随包发布时，不生成虚假下载地址。
