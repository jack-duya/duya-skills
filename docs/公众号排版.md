# 公众号排版

[返回首页](../README.md) · [新手入门](新手入门.md) · [安装指南](安装指南.md) · [12 主题在线预览](https://jack-duya.github.io/duya-skills/wechat-gallery/)

渡鸦现在可以把已有文章排成公众号阅读稿，也可以写好文章后直接完成排版。你会得到可打开的预览页、可复制的正文 HTML 和检查报告。使用 `duya-wechat` 可直接进入公众号能力，也可以继续向主入口 `duya` 提问；12 套主题是这项能力中的视觉选择。

## 三种最直接的用法

在 Codex 中使用 `$duya-wechat`；Claude Code 独立 Skill 对应 `/duya-wechat`，插件对应 `/duya:duya-wechat`。主入口 `$duya`、`/duya` 或 `/duya:duya` 仍能接收相同请求。把示例中的路径替换成你的文件地址，或直接在消息后粘贴正文。

### 1. 已有文章，只做排版

```text
$duya-wechat 把这篇文章排成公众号格式：D:/文章/账号多就能获客吗.md。
不要改正文、段落顺序、数字、报价、作者、引用或标点，也不要加关注引导和签名。
主题你根据文章选一个，直接给我预览页和可复制正文。
```

渡鸦读取文章，按原结构选择主题并生成文件。没有指定主题也能直接做，不需要先填业务问卷或逐个浏览主题。

### 2. 写一篇文章，再完成排版

```text
$duya-wechat 根据下面这些真实材料，写一篇给装修公司老板看的公众号文章，
解释为什么增加账号不一定增加有效咨询。不要编客户故事，不要默认推销课程。
写好后直接排版，保留一份正文稿，给我可以打开和复制的预览页。

我的材料：……
```

渡鸦先把内容写完整，再用同一份正文生成排版。标题、摘要、作者等以你提供的信息和本次写作要求为准，没有资料不会自动补一个作者或结尾话术。

### 3. 对比主题，改样式不改内容

```text
$duya-wechat 用我这篇文章生成 12 套主题的对照预览，我先看风格。
不要改任何正文内容。选定主题后，帮我生成那一套的最终排版文件。
文章路径：D:/文章/线上获客团队.md
```

渡鸦生成同一篇文章的主题对照入口。选定后仍可提出具体调整，例如“正文间距紧一点”“引用不要那么醒目”。只改样式时，不会顺带重写正文。

## 12 套主题怎么选

[打开 12 主题在线画册](https://jack-duya.github.io/duya-skills/wechat-gallery/)，可以用同一篇示范文章比较各套风格。也可下载仓库或安装包，用浏览器打开 [docs/wechat-gallery/index.html](wechat-gallery/index.html)；生成自己文章的预览直接打开本地输出文件。GitHub 仓库里的 HTML 文件页面展示源码，在线画册才是可以点击和复制的预览。

每套主题的名称、使用场景与设计差异见[主题选择指南](../skills/duya/references/wechat-themes.md)。主题影响标题、正文节奏、引用、列表和表格等视觉呈现，不改变文章的观点与业务事实。

默认由渡鸦根据文章选一套，交付时说明选择理由；你也可以直接指定主题。不要为了换主题重新写整篇文章。相同主题可用于多个行业，同一行业也可以根据文章用途选择不同主题。

## 能用哪些材料

| 材料 | 如何处理 |
|---|---|
| Markdown 文件或粘贴的 Markdown | 按已有标题、段落、列表等结构转换 |
| 普通纯文本 | 保留正文和段落，准备为文本输入；不擅自补目录或编号 |
| Word、PDF、网页富文本 | 先由当前 AI 客户端可用的工具提取，保留转换稿，再排版 |
| 已有 HTML 页面 | 先提取文章正文并核对；不直接把网页的脚本、菜单和页面外壳复制进公众号 |

Word、PDF 的读取取决于你的客户端工具，内置 Python 排版脚本不直接读取这些格式。扫描版 PDF、复杂表格或图片提取失败时，渡鸦会说明具体缺失；它不会只看到路径就声称已经读完。

## 交付文件与复制方式

以 `article.md`、主题 `raven-brief` 为例：

| 文件 | 你可以做什么 |
|---|---|
| `article.raven-brief.preview.html` | 用浏览器打开，查看文章并复制正文 |
| `article.raven-brief.html` | 干净的正文 HTML，保留作检查或其他工具输入 |
| `article.raven-brief.report.json` | 查看本次检查结果和仍需注意的项目 |

使用时按这三步操作：

1. 打开预览页，点击复制按钮。
2. 到公众号编辑器中粘贴。浏览器不允许自动复制时，按页面提示选中正文，再按 `Ctrl+C`（Mac 为 `⌘C`）复制。
3. 在公众号编辑器和手机预览中确认图片、表格、链接、段落与样式，再按你的正常流程发布。

复制的是排版正文，不是 HTML 源码，也不包含预览页的按钮和工具栏。静态检查和浏览器预览不能代替实际公众号粘贴检查；平台可能调整样式，图片也可能需要重新上传。

## 这次会改什么，不会改什么

| 你提出的任务 | 渡鸦处理的范围 |
|---|---|
| 只排版 | 改视觉样式，保留正文、事实、顺序、引用和标点 |
| 只改某段 | 只改指定内容；已要求排版时再更新对应排版文件 |
| 润色并排版 | 先按要求改稿，保留可核对正文，再生成排版 |
| 换主题 | 重新生成视觉表现，不借机增加案例、报价或引导 |

默认不添加作者签名、互动话术、购买按钮、英文标签或摘要；不对每一段强制划重点；不把删除线改成高亮。部分主题会为二级标题加视觉序号，标题原来已有编号时不重复添加。你可以直接说“不要新增编号”或“保持原有视觉结构”，渡鸦会关闭主题新增编号，并保留原文的编号。如果需要改正文或新增引导，直接说清希望修改的内容和范围。

## 安装与更新

公众号排版从 **0.3.0** 加入渡鸦，**0.4.0** 增加了真实注册的 `duya-wechat` 快捷入口与更新能力。原有商业判断、获客方案、各平台写作和团队设计仍可通过主入口使用。

首次普通安装，或将没有更新器的 0.3.x 及更早普通安装升级，执行一次完整安装；插件用户沿用客户端原生插件更新：

```bash
npx -y skills add jack-duya/duya-skills -g --skill '*'
```

这会安装仓库中的 14 个入口及共享核心。按提示选择当前客户端并更新已有项目；旧目录有自己改过的官方文件时，先另存。完成后重新加载技能或新开对话。0.4.0 起可直接对渡鸦说“更新渡鸦”，只想查看时说“检查更新”。备份、安装渠道与重新加载方式见[更新指南](更新指南.md)。

要运行排版，客户端需要能读写文件并执行 Python 3.10+，无需额外 pip 依赖。手动安装请将 `skills` 下的 `duya` 和全部 `duya-*` 目录一起复制为同级文件夹；主题资产、参考规范与工具位于完整 `duya` 核心中，不需要单独安装 12 个主题。只复制 `duya-wechat` 或只更新 `SKILL.md` 会缺少实际排版工具。仅安装完整 `duya` 核心也能自然对话排版，但没有独立的 `duya-wechat` 命令。

开发者的命令、输入边界和校验流程见[公众号排版执行规范](../skills/duya/references/wechat-typesetting.md)。
