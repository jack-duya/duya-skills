# 问题-哪些信息会改变这次建议

## 仍待确认

- 这家保洁店实际提供哪些服务，哪些需要额外安排？
- 本地客户首先在意的具体家务问题是什么？
- 这次内容是让人认识问题，还是回答已经提出的比较问题？

## 怎样处理新资料

用户给服务清单，就据此修订应用稿中的具体范围；用户给咨询原话，就检查客户是否已经有明确需求。没有这些资料，保留本条问题，不编答案，也不把补齐数据当作学习的前置作业。

## 下次调用示例

“从这个知识库找到按读者处境选择内容入口的方法。现在客户已经问油烟机拆洗包不包含，沿用它的边界，帮我根据我给的服务清单写回复。”

Agent 应实际读取相关笔记与服务清单，再给回复。只说“我记住了”不等于完成检索。
