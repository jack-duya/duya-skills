## 它在回答什么

保洁新号的内容，应先讲家务情绪还是直接介绍服务？

## 材料中的主张

1. 尚未主动寻找服务的同类人，可以从其真实家务处境进入，再回到有关的任务。
2. 愿意继续看，不等于愿意买；考虑服务的人需要实际范围和限制。
3. 已在搜索具体服务问题的人，应先得到直接答案。
4. 以上是有条件的判断，没有实际效果数据，不能据此保证获客。
