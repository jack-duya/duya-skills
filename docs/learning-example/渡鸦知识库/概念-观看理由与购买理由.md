# 概念-观看理由与购买理由

## 用普通话解释

观看理由回答：为什么现在愿意继续看？购买理由回答：为什么愿意为解决这个问题选择这项服务？

具体家务场景可能让人感到被理解；实际服务范围和可信的过程信息才可能进一步帮助其选择。两者相关，但不能互相替代。

## 例子与反例

“每天擦完灶台又看见水槽里的碗”可以解释家务收不了尾的感受，却没有回答油烟机拆洗是否包含在服务里。用户已经在问后一个问题时，继续只说“我懂你的累”是不够的。

## 不应过度推断

本例没有讨论实际使用后的满意度，更没有证明某句话会让客户购买。
