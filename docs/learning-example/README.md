# 量子阅读 · 可打开的示例知识库

这是由渡鸦随包保存工具实际生成的教学笔记，不是客户项目或获客效果报告。包含 5 篇知识笔记、1 篇索引，以及供回查的原始教学材料。

## 先看这里

- 在 Obsidian 选择“打开文件夹为仓库 / Open folder as vault”，选本目录。无需额外插件。
- 打开 [量子阅读示例索引](渡鸦知识库/量子阅读示例索引.md)。笔记中的 `[[…]]` 在 Obsidian 中成为内部链接。
- 点击关系图可以查看笔记连接；打开某篇方法后，用局部关系图查看邻近关系。
- 未使用 Obsidian 时，直接打开下面的 Markdown 文件即可；GitHub 不把 Wikilink 显示为普通链接。
