# duya-skills 新手入门

如果你想把自己的生意搬到线上，却不知道先选平台、拍什么、怎样把人吸引过来；或者已经在做内容，但咨询不对、稿子不好、团队一直忙不出结果，可以从这里开始。

**duya-skills 是渡鸦的商业与线索获客 Skills 体系。** 你和墨涅斯直接交流，它结合商业判断、内容方法和实际材料，完成当前需要的判断、方案、文案或团队安排。它关注的是合适的人为什么需要你、为什么愿意了解你，以及你怎样持续把这件事做出来。

第一次使用，从 **`duya` 主入口**开始即可；已经知道要做什么，可以直接使用 **12 个专业子 Skill 的快捷入口**。它们共用墨涅斯的判断方法、已有业务背景和知识库，不需要重复交代。另有 `duya-update` 负责检查和更新版本。

还没安装？先按 [安装指南](安装指南.md) 完成完整安装，再回到这里。本文示例使用 Codex 的 `$` 前缀；Claude Code 独立安装改用 `/`，本仓库插件安装改用 `/duya:`。例如 `$duya-video` 对应 `/duya-video` 或 `/duya:duya-video`，后面的自然语言保持不变。

**0.4.0 新增：** 12 个专业快捷入口、一句话动态更新，以及下面的完整命令目录。公众号写作与 12 套原创排版主题可以通过 `$duya-wechat` 直接使用，也可以继续交给 `$duya`。[排版教程](公众号排版.md) · [在线主题画册](https://jack-duya.github.io/duya-skills/wechat-gallery/)

## 第一次怎么用

安装完成后，在启用 duya 的对话里说一个真实问题就可以开始。

### 还不知道该从哪里开始

可以直接复制这段，再把行业换成自己的：

```text
$duya 我做本地装修，过去主要靠熟人介绍。
现在想从线上找业主，不知道先做抖音、小红书还是视频号。
我们有工地实拍，但老板不擅长长时间口播，暂时只有一个人做内容。
帮我选一个能开始的方案，把账号怎么介绍、先发什么、第一条怎么拍一起做出来。
```

这段话已经提供了足够多的起点：你在卖什么、希望吸引谁、有什么材料、谁来做，以及本轮要拿到什么。

你应该得到的不是一张“各平台都可以试试”的比较表，而是：

1. 当前优先做哪条路线，以及为什么符合你的生意和人手。
2. 账号角色、主页介绍和适合起步的内容方向。
3. 一条完整的首发稿，以及真实素材能支持的拍法。
4. 哪种新情况出现后，需要调整原来的选择。

如果只知道自己“想线上获客”，也可以直接说。墨涅斯会利用已经给出的信息，只补问会改变建议的关键问题。

### 已经遇到了具体卡点

直接把卡点交出来：

```text
$duya 我发的装修视频，评论区大多在讨论工艺，业主咨询不多。
我以为是账号太少，准备再做几个号。先帮我判断这个想法对不对。
这是我最近一条的文案：……
```

这里会先分清“想增加合适咨询”和“准备增加账号”之间的关系。现有内容在吸引同行，和现有内容已经有效但覆盖不足，需要不同的解决办法。判断之后应继续落到具体改稿、内容形式或分发安排。

### 只想马上完成一件小事

不需要先讲完整商业背景：

```text
$duya 这篇小红书正文已经定了，只帮我改标题，别重写正文：……
```

```text
$duya 找几条适合家庭日常保洁的图文模板，说明哪条最适合商家身份，再改一条给我。
```

```text
$duya 下面这段短视频口播太像培训讲课，改成装修老板在工地跟业主说话的感觉：……
```

```text
$duya 这篇文章不改文字，自动选主题，输出可复制到公众号的 HTML：……
```

小任务直接完成。已经明确的定位、风格和素材，不会因为换了一个内部能力就让你重新交代。

## 怎样更新

正在使用渡鸦时，直接说：

```text
更新
```

在其他对话中可以明确指定，或者使用更新快捷入口：

```text
更新渡鸦
```

```text
$duya-update
```

渡鸦会检查当前实际使用的安装位置，查询 [官方 GitHub 仓库](https://github.com/jack-duya/duya-skills) `main` 分支的最新提交，下载并更新这一套渡鸦。它会告诉你旧版本、新版本、实际更新位置和是否需要重新加载。即使版本号没有改变，也会比较提交；已经最新时会直接说明。

普通目录更新会先备份将被替换的官方文件，保留未被官方管理的个人文件；独立存放的 `~/.duya/memory` 不参与覆盖。客户端管理的插件走对应的插件更新方式。更新针对当前安装及指向它的已有连接，不会扫描替换电脑上的所有副本，也不会更新其他项目的 Skills。

“更新这篇文案”“更新报价”仍然是内容任务，不会触发版本更新。普通聊天应用没有本地执行权限时，无法仅凭一句话替你改安装文件；渡鸦应说明具体缺少的能力。

**0.3.x 及更早的版本还没有内置更新入口。**第一次升级可重新执行完整安装命令；此后即可使用上面的一句话更新。若用 Codex 全局安装，可运行：

```bash
npx -y skills add jack-duya/duya-skills -g --skill '*' --agent codex
```

其他客户端与插件用户按 [安装指南](安装指南.md) 选择原来的安装方式。完成后新开对话，避免继续使用旧版提示词。更新范围、备份与故障处理见 [更新指南](更新指南.md)。

项目长期记忆与插件文件分开存放。平时直接使用内置保存功能即可，不要把自己的客户材料、业务档案或成稿存进将来会被更新覆盖的安装目录。

## duya-skills 怎样工作

### 1. 从你当前真正要完成的事情开始

你提供业务、问题、材料或一个具体修改要求。墨涅斯先判断这轮需要交什么：首选方案、一段改稿、一篇文章、一组内容，还是一个团队安排。

如果任务已经清楚，就直接制作；如果你说的是某种现象或投入选择，会先判断这是不是值得解决的那个问题。

### 2. 用商业与获客知识参与判断

“万流归因诀”在这里指 **由果推因、由因解果**：从现象寻找有依据的原因，重新定义要解决的问题，再从原因出发选办法。

例如，“账号不够，去哪买号”可能是缺覆盖，也可能是内容没有让合适的人看懂购买理由。墨涅斯要结合当前业务比较内容改造、自营矩阵、素人合作和达人合作，而不是把每个问题都归结为“多发”或“先别扩张”。

### 3. 按需读取方法、知识和真实参考

写短视频会读取短视频方法；处理团队会读取岗位与协作知识。需要找模板、新赛道创作或重做没有网感的稿件时，会使用渡鸦模板库或已有材料。

模板库没有完全相同的赛道时，可以沿相似人群、需求或表达机制找参考，再用你的真实业务重写。例如，研究家庭生活内容的观看理由，可以帮助保洁内容找切口；商家身份与实际服务仍然要保持清楚。

### 4. 本轮直接交付成果

你要稿件，就交完整稿件；你要计划，就把选择落实到现有人手、材料和具体工作。多个能力需要配合时，系统沿用已有背景完成衔接，不让你复制一份报告，再发给“下一个 Skill”。

### 5. 根据你的反馈修正并接着做

可以继续说：

```text
方向对，但这条太像广告。保留开头，把后半段改成真实的家庭场景。
```

```text
你理解错了。我不是给业主装修，我是给装修老板做获客陪跑。按这个重新写。
```

```text
这个安排我们做不了。老板每周只能参与一次取材，按这个限制重排。
```

新事实、明确的否决和实际限制，会改变后续建议。你提供业务结果时，系统会利用；没有结果数据，也可以继续解决当前问题。

## Skill 全目录

0.4.0 完整包提供 **14 个注册入口：1 个主入口、12 个业务快捷入口和 1 个更新入口**。业务能力仍由 12 个专业方法包与 23 篇专题知识库支撑；快捷入口直接进入对应方法，共用同一套判断内核。下面按实际任务分组，列出每项的适用时机、可复制示例和主要产出。

### 主入口与商业获客判断

#### `$duya`｜墨涅斯主入口

**什么时候用：** 任何商业与线上获客问题；不知道该先做什么，或者需要把几个环节连起来完成时，也从这里进入。

**你可以这样说：**

```text
$duya 我已经做了不少内容，但越做越乱。
这是我的产品、最近的稿件和团队情况，帮我判断现在最值得先改什么，并把能改的先改出来：……
```

**你会得到：** 有首选和理由的判断，以及当前能完成的方案或作品。系统负责选择和衔接内部能力。

#### `$duya-positioning`｜客户与商业定位

**什么时候用：** 不知道优先找哪种客户；产品介绍全是“专业、服务好”；有人感兴趣但不购买；前端吸引的人接不到现有服务。

**你可以这样说：**

```text
$duya-positioning 我给本地商家做短视频陪跑，不负责替他们拍摄。
客户以为交钱就能等着来客资，后续配合很差。
帮我判断应该服务谁、怎样讲购买理由，把对外介绍直接改好。
```

**你会得到：** 优先客户及其具体处境、值得表达的购买理由、产品能承担的承诺，以及可直接使用的定位或介绍。

[查看能力说明](../skills/duya/internal/duya-positioning/GUIDE.md)

#### `$duya-acquisition`｜获客体系搭建

**什么时候用：** 从零做线上获客；选平台、形式和打法；已有线下业务想上线；需要把账号介绍、素材准备和首批内容连起来。

**你可以这样说：**

```text
$duya-acquisition 我做搬家后清洁，有真实现场，暂时一个人做内容。
帮我选择主要平台和制作形式，写好主页介绍，再给首批内容和第一条完整稿。
```

**你会得到：** 适合当前资源的主要路线、必要准备、真实素材安排、能开始执行的首批工作。需要时会直接完成第一条内容。

[查看能力说明](../skills/duya/internal/duya-acquisition/GUIDE.md)

#### `$duya-diagnose`｜获客问题诊断

**什么时候用：** 没流量、有播放没咨询、咨询人群不对、模板无效、问价后消失；也适合判断扩账号、加人或换平台能否解决当前卡点。

**你可以这样说：**

```text
$duya-diagnose 我的装修视频有人看，但来问的主要是同行。
这是三段现有文案，帮我找最该先改的原因，选一段直接重写。
```

**你会得到：** 当前最有依据的原因判断、会改变判断的条件，以及针对原因的具体改法。能改的稿件或安排在同一轮完成。

[查看能力说明](../skills/duya/internal/duya-diagnose/GUIDE.md)

### 内容创作与传播

#### `$duya-content-plan`｜选题与内容规划

**什么时候用：** 不知道拍什么；新号没有相关观看入口；每天内容很散；业务介绍太多；希望让一组作品承担不同作用。

**你可以这样说：**

```text
$duya-content-plan 我做家庭保洁，新号不想一上来全发服务广告。
从日常家务处境出发，给我 6 个有区别的选题。
说明每条适合什么形式，再挑最值得先做的一条写完整。
```

**你会得到：** 具体选题与切口、相关的人为什么愿意看、适合的形式、需要的真实素材和优先次序。既可以设计泛垂直入口，也可以安排帮助理解服务、比较和咨询的内容。

[查看能力说明](../skills/duya/internal/duya-content-plan/GUIDE.md)

#### `$duya-research`｜模板与内容研究

**什么时候用：** 想找图文模板、对标作品；想知道一条内容为什么有吸引力；需要把其他赛道的表达方式迁移到自己的业务。

**你可以这样说：**

```text
$duya-research 去渡鸦模板库找适合家庭保洁的小红书参考。
我是商家，不要把我写成求推荐的消费者。
选一条解释为什么能借鉴，再按我的身份改成完整稿。
```

**你会得到：** 实际取得的模板与编号、值得借鉴的具体机制、需要替换的事实与场景，以及你要求的改编稿。给了作品链接或转写，也可以就材料本身进行拆解。

[查看能力说明](../skills/duya/internal/duya-research/GUIDE.md)

#### `$duya-video`｜线索短视频

**什么时候用：** 写逐字稿、改开头、做现场旁白、访谈或轻 IP 内容；把专业表达改成客户听得懂的内容；同一题材适配多个短视频平台。

**你可以这样说：**

```text
$duya-video 老板不想背长稿，我们有清理缝隙和收尾检查的现场素材。
写一条面向第一次请保洁的人的视频，给完整旁白和镜头顺序。
用实际过程回答顾虑，不要写“专业团队、品质服务”。
```

**你会得到：** 能说出口的完整稿、能对应素材的镜头安排，以及必要的字幕或表达版本。短视频的共同内容逻辑可以跨平台复用，具体发布场景再作调整。

[查看能力说明](../skills/duya/internal/duya-video/GUIDE.md)

#### `$duya-xhs`｜小红书与图文

**什么时候用：** 写标题、封面文字、单图、完整笔记、多页图文；把已有内容改成适合浏览、讨论或主动搜索的表达。

**你可以这样说：**

```text
$duya-xhs 写一篇给第一次请家庭保洁的人看的小红书。
主题是“下单前先说清哪些地方要做”，不要虚构亲身踩坑。
给标题、封面文字、完整正文和一条商家身份的首评。
```

**你会得到：** 可以直接使用的标题、封面文字、正文或逐页文案，以及任务确实需要的互动表达。只改标题时，也会只处理标题。

[查看能力说明](../skills/duya/internal/duya-xhs/GUIDE.md)

#### `$duya-wechat`｜公众号写作与排版

**什么时候用：** 写完整公众号文章、产品理念、商业分析、案例解读或课程应用；改文章论证、开头、结构与表达；把已有定稿排成可预览、可复制的公众号正文。

**你可以这样说：**

```text
$duya-wechat 面向装修老板，写一篇“工地视频拍得很专业，为什么业主还是不来问”。
核心讲清楚同行想看工艺，业主还要判断选择风险。
写完整正文，使用下面的真实材料，不编客户故事：……
```

已有定稿可以直接说：


### 学习与长期记录

#### `$duya-learning`｜量子阅读与学习

**什么时候用：** 读课程、书、长文；看懂一个方法；比较新旧观点；把有用知识整理成能继续使用的方法或知识库。

**你可以这样说：**

```text
$duya-learning 读这份课程，重点找能改善我们获客内容的方法。
说明它解决什么问题、怎样做、什么条件下不适用。
用我现有的一条文案演示改法，把有价值的方法保存到这个项目。
```

**你会得到：** 对资料的清楚解释、有条件和反例的方法、实际应用示范，以及需要的整理文件或保存结果。量子阅读在这里是阅读与应用的方法名称。

第一次使用可以只说“解释这一段”，也可以要求“读完整门课，再用我的旧稿示范”。渡鸦会完成**审查材料 → 提纯方法 → 用应用和反例检验 → 整理成可复用知识**；不把整课压成目录摘要，也不要求每阶段交作业。

希望保存到 Obsidian，可以直接给已经选好的库：

```text
$duya-learning 把刚才值得复用的方法存进我的 Obsidian 知识库：D:/我的知识库。
沿用已有分类，保留来源、适用条件、反例和这次应用。
关联实际存在的相关笔记；同名内容不同时不要静默覆盖。
完成后告诉我保存了哪些文件、从哪篇开始读。
```

以后这样找回来用：

```text
$duya-learning 从 D:/我的知识库 找上次关于内容入口和购买理由的方法。
先读相关笔记，再按我这次给出的服务清单写一条客户回复：……
```

示例路径需换成自己的目录。对话中已选定的库直接使用；未知时先确认位置或只读查找候选，多个库不猜。**Obsidian 是可选存储与阅读工具，不需要额外 MCP；不用它也能交付普通 Markdown。**实际保存需要当前客户端有文件读写能力，没写入成功就不算存好了。

## 常见场景与动态编排

你不必安排内部调用顺序。系统围绕这轮要完成的成果，组合真正需要的能力；同一句请求也可能同时完成判断和制作。

### 1. 从零搭建自己的线上获客体系

```text
$duya 我做家庭日常保洁，有现场素材，不想出镜。
帮我选主要路线，完成账号介绍、首批 5 个选题和其中 1 条完整内容。
```

通常会把客户判断、路线选择、选题和图文或视频制作连起来。已经清楚的服务不重复诊断，第一条成稿沿用前面确定的人群和制作条件。

### 2. 有播放，但没有想要的客户

```text
$duya 这条内容播放还可以，但评论都是同行。
我想找的是业主。先看问题出在哪，再直接给可替换的稿：……
```

先从现有材料判断观看理由与购买理由有没有错位，再把修改落到开头、画面和解释。同一轮交付修改后的作品，不只说“提高精准度”。

### 3. 从爆款参考做出自己的内容

```text
$duya 找一条与第一次请保洁相关的图文参考。
可以借相邻赛道的结构，但身份和服务事实用我的。
给最终稿，附一句为什么选这个参考。
```

模板研究与创作配合：取得参考，找到可迁移的表达关系，再写自己的作品。你也可以先提供喜欢的内容，直接要求拆解并改写。

### 4. 同一份素材做成多种内容

```text
$duya 这是一段真实工地采访。
做成一条短视频、一篇小红书和一个公众号文章开头。
保持同一个购买理由，但按不同形式重写，不要只是复制粘贴：……
```

先确定采访中的关键事实和读者判断，再分别制作。短视频安排能说和能拍的表达，图文组织首屏与阅读，长文展开一个值得继续读的主张。

### 5. 团队很忙，但老板越来越累

```text
$duya 两个员工都在做内容，但找素材、改稿、最后定选题还是我。
我给你现在的一天工作过程，帮我改分工，再给员工一个明天就能开始的任务：……
```

重点检查材料、判断权和职责是否安排对，再决定是否需要招人。交付具体工作样本、交接方法和反馈方式。

### 6. 把新课程变成自己的方法

```text
$duya 读这份课件，和我们已经采用的内容方法对照。
找出能补充的、条件不同的和真正冲突的地方。
用一个获客任务演示，再保存值得继续使用的方法。
```

阅读、方法比较、业务应用和长期记忆配合。保留来源与适用条件，避免每学一门课就把原有方案全部推翻。

需要看完整交付，可以阅读[量子阅读教程中的保洁静态示例](量子阅读.md#完整静态示例保洁内容该先讲情绪还是直接讲服务)：从四段原料，到方法与边界、两条完整成稿、五篇关联笔记和索引，再到下次检索后按新服务清单写回复。示例可在普通文件夹中阅读，也可用 Obsidian 打开。

### 7. 下次接着做

```text
$duya 继续“家庭保洁”项目，沿用上次确定的不出镜形式。
这次新增了厨房清洁的素材，帮我写下一条。
```

项目记忆存在且当前环境能访问时，读取与本轮有关的背景，再利用新素材制作。第一次在另一台电脑或新环境使用，需要先迁移已有记忆，具体见 [常见问题](常见问题.md)。

更多连续对话示范和成稿片段见 [使用案例](使用案例.md)。

## 使用习惯

- **先说你要拿到什么。** “帮我判断”与“判断后把第一条写出来”，对应的交付范围不同。
- **给已有的真实材料。** 一段文案、一次客户提问、可拍的现场，通常比堆很多形容词更有用。不需要先凑齐一套数据。
- **直接指出不对的地方。** 说“这一句像广告”“你写给同行了”“这个镜头我们拍不了”，比笼统说“再高级一点”更容易改到位。
- **需要接续时说明项目。** 不同客户、不同生意使用容易辨认的项目名称，后续更容易恢复正确背景。
- **把范围说清楚。** 只改标题就说只改标题；要完整文章就说完整文章；希望做 6 条，就说明数量与可用素材。
- **结果给了就用，没给也能继续。** 有新咨询或团队反馈可以补充，日常使用不要求填发布、客资或成交台账。
