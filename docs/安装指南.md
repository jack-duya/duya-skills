# 安装指南

[返回首页](../README.md) · [新手入门](新手入门.md) · [更新指南](更新指南.md) · [常见问题](常见问题.md)

安装完成后，你可以直接把业务、材料或卡点交给 `duya`，也可以选择 `duya-video`、`duya-wechat` 等快捷入口。渡鸦核心注册 **14 个入口：1 个主入口、12 个业务快捷入口、1 个更新入口**，共用 12 项业务方法和 24 篇知识。

本仓库另有独立的 [墨界采集助手](../skills/moyaclaw-collect/SKILL.md)。使用 `--skill '*'` 安装仓库全部技能时会同时选择它；该目录不属于渡鸦核心更新器管理的14个组件，安装和使用条件以其说明为准。

量子阅读可直接交付 Markdown 知识库；如需存进 Obsidian，指定已有库目录即可，无需为此额外安装 MCP 或社区插件。保存工具需要 Python 3.10+ 和目标目录写入权限。具体操作、完整案例与示例库见 [量子阅读教程](量子阅读.md)。

**第一次安装，推荐使用下面的通用安装方式，一次安装完整包。**先装到你正在使用的 AI 客户端，再连接模板库。只想先试商业判断、文案改写，也可以先完成安装。

## 选择适合你的方式

| 你正在使用 | 安装方式 | 如何开始 |
|---|---|---|
| Codex | 通用命令，选择 `codex` | `$duya` 自然提问；`$duya-video` 等快捷入口直接工作 |
| Claude Code | 通用命令，或本页的插件安装 | 独立 Skill 用 `/duya`、`/duya-video`；插件用 `/duya:duya`、`/duya:duya-video` |
| Cursor | 通用命令，选择 `cursor` | 在 Agent 对话中说“使用 duya，……” |
| 其他支持 Agent Skills 的客户端 | 通用命令中选择对应客户端，或手动导入完整目录 | 按客户端的技能选择方式启用 |
| 只有普通聊天框的应用 | 先确认它是否支持 Skills、文件读取和工具调用 | 粘贴主提示词只能体验部分能力 |

各客户端的模型、文件、网络和工具权限不同。通用安装工具支持某个客户端，不等于渡鸦已在该客户端完成全部功能实测。

## 方式一：通用安装

### 1. 准备好终端

Windows 打开 PowerShell 或 Windows Terminal；macOS 打开“终端”。你也可以在 AI 编辑器中打开内置终端。

先分别输入：

```bash
node --version
```

```bash
npx --version
```

两条命令都能显示版本号就可以继续。找不到命令时，先从 [Node.js 官网](https://nodejs.org/en/download)安装 LTS 版本，再重新打开终端。

下载公开 GitHub 仓库还需要能访问 GitHub；如果安装过程提示找不到 Git，请从 [Git 官网](https://git-scm.com/downloads)安装后重新打开终端。

### 2. 安装完整渡鸦包

复制下面这一条命令：

```bash
npx -y skills add jack-duya/duya-skills -g --skill '*'
```

如果出现客户端选择，选你实际使用的客户端。出现安装方式选择时，可采用默认方式；Windows 遇到链接权限问题时，改用下文的 `--copy` 方式。

`-g` 表示在当前电脑的用户范围安装，便于不同项目使用。`--skill '*'` 选择 **jack-duya/duya-skills 这个仓库的全部 14 个入口**；保留星号两侧的引号。它不是 `--all`，不会要求给所有 Agent 都安装。

`duya` 保存核心、12 项业务方法、24 篇知识与工具；同级 `duya-*` 是直接调用这些方法的快捷入口。它们共用核心，不复制 14 份知识库。需要完整快捷菜单时一次装全，不要只装某个 `duya-video` 文件夹。

也可以直接指定客户端：

**Codex：**

```bash
npx -y skills add jack-duya/duya-skills -g --skill '*' --agent codex
```

**Claude Code：**

```bash
npx -y skills add jack-duya/duya-skills -g --skill '*' --agent claude-code
```

**Cursor：**

```bash
npx -y skills add jack-duya/duya-skills -g --skill '*' --agent cursor
```

上面三条只需要运行你对应的一条。这里的 `skills` 是 [Vercel Labs 的通用安装工具](https://github.com/vercel-labs/skills)，不是渡鸦另一个需要购买的软件。

只想保留主入口时，可将 `--skill '*'` 改成 `--skill duya`。这样仍能通过 `$duya` 自然对话使用全部业务能力与更新方法，但不会注册独立的 `$duya-video`、`$duya-update` 等快捷命令。

### 3. 确认安装成功

完整安装后应发现并安装 14 项：`duya`、12 个业务快捷入口和 `duya-update`。也可以查看已安装的全局技能：

```bash
npx -y skills list -g
```

然后新开一个 AI 对话。在 Codex 中发送：

```text
$duya 我做同城家政，目前只有老板和一个兼职剪辑，想开始线上获客。帮我判断先做什么平台、拍什么内容，并给一条今天能拍的稿。
```

也可以直接试用业务快捷入口：

```text
$duya-video 把这段口播改成家政老板能直接拍的完整脚本，不编造客户故事：……
```

Claude Code 独立安装把开头换成 `/duya` 或 `/duya-video`；其他客户端可以说“使用 duya”，或从其技能列表中选中对应能力。完整名称见[主页快捷表](../README.md#能力一览)。

**成功现象：**客户端能找到 `duya` 与已选择的快捷入口，快捷入口能读取同级核心，回答能进入你给出的业务场景，给出具体判断或成稿；没有报知识库、GUIDE 或脚本文件缺失。AI 自称“已启用”不能单独证明安装成功，技能列表和实际文件读取更可靠。

公众号排版、本地记忆和普通安装更新器需要 **Python 3.10+**、文件读写及脚本执行能力，使用 Python 标准库，无须额外 pip 依赖。普通业务问答不要求先运行这些工具。

### 4. 需要不同安装范围时

只想让当前项目使用：先进入该项目目录，再运行不带 `-g` 的命令。

```bash
npx -y skills add jack-duya/duya-skills --skill '*' --agent codex
```

Windows 链接失败，或你希望使用独立复制的文件：

```bash
npx -y skills add jack-duya/duya-skills -g --skill '*' --agent codex --copy
```

把 `codex` 换成对应的客户端名称即可。安装范围不同时，后续更新和排查也要检查对应范围。

## 方式二：Claude Code 插件安装

如果你主要使用 Claude Code，可以通过渡鸦插件市场安装，技能与模板 MCP 配置一起交给客户端加载。**同一个客户端选一种安装方式即可**，不必同时装通用 Skill 和插件。

在终端依次运行：

```bash
claude plugin marketplace add jack-duya/duya-skills
```

```bash
claude plugin install duya@duya-skills
```

完成后重启 Claude Code，输入：

```text
/duya:duya 我做同城家政，先帮我判断线上获客应该从哪里开始。
```

这里前面的 `duya` 是插件名，后面的 `duya` 是主入口，所以命令是 `/duya:duya`。完整插件还注册 `/duya:duya-video`、`/duya:duya-wechat`、`/duya:duya-update` 等快捷入口。终端显示安装成功后，还要在实际对话中验证技能；模板连接可用 `/mcp` 查看，并按本页示例真实检索一次。

插件自带根目录 `.mcp.json`。客户端加载插件时会读取它；是否需要确认启用、远程服务能否连接，还取决于你的客户端设置和网络。如果工具已经可用，就不用再运行本页的手动 MCP 添加命令。

以上目录和命令依据 [Claude Code 插件市场官方文档](https://code.claude.com/docs/en/plugin-marketplaces)；MCP 加载位置依据 [插件参考文档](https://code.claude.com/docs/en/plugins-reference)。本仓库是渡鸦维护的独立市场，不是 Anthropic 官方市场收录。

## 方式三：手动安装

不使用命令行安装工具时，也可以直接复制技能目录。

1. 打开[仓库首页](https://github.com/jack-duya/duya-skills)，点击 **Code → Download ZIP**，解压。
2. 找到压缩包里的 `skills` 文件夹，确认其中有 `duya` 和 13 个 `duya-*` 文件夹。
3. **将这 14 个文件夹一起复制**到对应客户端的同一个 Skills 目录，保留 `duya` 内的所有子目录。它们必须是同级关系。
4. 新开对话并按上面的示例试用。

| 客户端 | 个人 Skills 目录示例 |
|---|---|
| Codex | `~/.codex/skills/` |
| Claude Code | `~/.claude/skills/` |
| Cursor | `~/.cursor/skills/` |

`~` 表示当前系统用户的主目录。Windows 通常是 `C:\Users\你的用户名`，macOS 通常是 `/Users/你的用户名`。若客户端配置了自定义目录，以其实际设置为准。

正确的目录形态：

```text
skills/
├── duya/
│   ├── SKILL.md
│   ├── package.json
│   ├── agents/
│   ├── references/
│   ├── internal/
│   ├── knowledge/
│   ├── assets/
│   └── tools/
├── duya-positioning/SKILL.md
├── duya-acquisition/SKILL.md
├── duya-diagnose/SKILL.md
├── duya-content-plan/SKILL.md
├── duya-research/SKILL.md
├── duya-video/SKILL.md
├── duya-xhs/SKILL.md
├── duya-wechat/SKILL.md
├── duya-live/SKILL.md
├── duya-matrix/SKILL.md
├── duya-team/SKILL.md
├── duya-learning/SKILL.md
└── duya-update/SKILL.md
```

不要只复制 `SKILL.md`，不要把快捷入口放进 `duya` 里面，也不要变成 `duya/duya/SKILL.md`。这些情况会造成核心依赖缺失或发现不到技能。只手动安装完整 `duya` 核心仍可自然对话使用全部业务，独立快捷命令则需要相应同级目录。

## 连接渡鸦图文模板库

模板库用于查找参考正文、模板编号和图片链接。它可以帮助渡鸦研究具体表达，并迁移到当前业务；找到模板不等于直接照搬，也不代表复制后必然获得相同效果。

**通过通用命令安装 Skill，不会自动给每个客户端注册 MCP。**按你的客户端完成下面一项即可；如果已经有同名服务且能调用，就不用重复添加。

### 连接信息

| 项目 | 填写内容 |
|---|---|
| 名称 | `moyaclaw-template-mcp` |
| 服务地址 | `http://43.242.194.25:3170/mcp` |
| 传输方式 | **Streamable HTTP / HTTP** |
| 鉴权 | 当前不需要 Token、Key 或登录 |

服务名称保留 `moyaclaw`，用于兼容现有工具配置。不要选 SSE 或 stdio；地址框只填实际 URL，不要把 Markdown 的方括号、括号一起粘进去。

### Codex

在安装了 Codex CLI 的终端运行：

```bash
codex mcp add moyaclaw-template-mcp --url http://43.242.194.25:3170/mcp
```

查看是否已有配置：

```bash
codex mcp list
```

如果你通过设置文件管理，也可在 Codex 用户配置 `~/.codex/config.toml` 中添加下面一段。已有同名段落时修改原段落，不要重复添加。

```toml
[mcp_servers.moyaclaw-template-mcp]
url = "http://43.242.194.25:3170/mcp"
```

重新打开对话后测试调用。CLI 参数已经核对本机帮助；其他配置项可查 [Codex MCP 官方文档](https://developers.openai.com/codex/mcp/)。

### Claude Code

在终端运行：

```bash
claude mcp add --transport http moyaclaw-template-mcp --scope user http://43.242.194.25:3170/mcp
```

`--scope user` 让当前用户的多个项目都能用。完成后在 Claude Code 对话里输入 `/mcp` 检查连接，再测试模板检索。参数与范围见 [Claude Code MCP 官方文档](https://code.claude.com/docs/en/mcp)。

### Cursor

打开 Cursor 的 MCP 设置，添加远程服务；或在用户配置 `~/.cursor/mcp.json` 中合并下面的内容。已经有其他服务时，只添加 `moyaclaw-template-mcp` 这一项，不要覆盖整个文件。

```json
{
  "mcpServers": {
    "moyaclaw-template-mcp": {
      "url": "http://43.242.194.25:3170/mcp"
    }
  }
}
```

如果界面要求选择传输类型，选择 **Streamable HTTP / HTTP**。配置位置见 [Cursor MCP 官方文档](https://cursor.com/docs/mcp)。

### 其他 MCP 客户端

使用本页连接信息添加远程 HTTP 服务。部分客户端需要显式指定 `type`：

```json
{
  "mcpServers": {
    "moyaclaw-template-mcp": {
      "type": "http",
      "url": "http://43.242.194.25:3170/mcp"
    }
  }
}
```

不同客户端字段可能不同，应以该客户端的远程 MCP 配置方式为准。Claude Desktop、普通网页聊天和 Claude Code 不是同一种安装环境，不要直接互抄配置后就认为已生效。

### 确认模板库连接成功

在 AI 对话里直接说：

```text
使用 duya，帮我从渡鸦模板库找 3 条家政保洁的小红书图文模板。请保留模板编号；如果没有准确赛道，说明你参考了哪个相近赛道。
```

客户端应真实调用模板工具，而不是凭空生成“库内模板”。连接后通常可以看到这些工具：

| 工具 | 能做什么 |
|---|---|
| `recommend_templates_tool` | 根据问题推荐候选模板 |
| `list_tracks_tool` | 查看模板库赛道 |
| `get_template_tool` | 根据编号读取一条模板的全文 |

拿到返回结果中的真实编号后，再说“把这条完整内容给我”。能够读到该编号的正文，才说明检索链路可用。

**浏览器直接打开服务地址出现 406，不能据此判断 MCP 坏了。**这是给 MCP 客户端连接的接口，不是一个供人浏览的网页；请以客户端握手和实际工具调用为准。

## 长期记忆需要额外设置吗

普通问答不需要先建立档案。你可以直接说：

```text
记住：这个项目叫“同城家政”，老板不做长口播，主要素材是员工真实服务过程。以后这个项目按这个条件来。
```

如果客户端允许运行 Python 和读写本地文件，渡鸦会用附带脚本保存。默认位置是：

```text
~/.duya/memory/<项目别名>/records.json
```

这个目录独立于技能安装目录，更新技能不会主动覆盖它。首次使用本地脚本时需要 Python 3.10+；无需额外 pip 依赖。

下次说“继续同城家政项目”，渡鸦应读取相关记录；你也可以说“把老板不出镜改成每周接受一次短出镜”或“忘记那条记录”。**只有实际保存成功才算记住。**在不支持文件工具的客户端中，它仍能完成当前回答，但无法承诺跨会话保存。

## 更新与卸载

### 0.4.0 起：直接对渡鸦说“更新”

在已经启用渡鸦的对话里说“更新”或“更新渡鸦”，它会更新当前实际使用的安装。也可以直接选择维护入口：

```text
$duya-update 更新渡鸦，保留我的项目记忆，完成后告诉我版本和怎样重新加载。
```

只想知道有没有新版本：

```text
$duya 检查更新，先不要修改文件。
```

普通安装会使用 Python 3.10+ 更新器，查询官方仓库 `main` 的最新提交，再固定这个 SHA 下载。替换官方文件前自动备份；未知个人文件和 `~/.duya/memory/` 保留。你改过的官方文件保存在备份中，安装位置使用新的官方内容；如要继续使用自己的改法，可从备份中对照恢复。

插件缓存交给客户端原生插件更新，不直接覆盖缓存；Git 源码目录只在官方来源正确、工作区干净且能快进时更新。遇到网络、权限、来源或本地修改问题，会说明未完成的原因，不能把下载尝试当作更新成功。更新后按客户端需要重新加载或新开对话。

当前版本以核心 `duya/package.json` 和更新器记录的实际更新状态为准。更新器不伪改通用安装工具的来源或锁文件；两种工具各自保留自己的记录。详细步骤、备份与恢复方式见[更新指南](更新指南.md)。

### 0.3.x 及更早版本：先完成一次升级

普通安装的旧版没有更新器，第一次需要运行完整安装命令。旧安装目录有自行修改的官方文件时，先将这些修改另存。Claude Code 插件用户按下节原生插件更新即可，无需重复安装独立 Skill。

```bash
npx -y skills add jack-duya/duya-skills -g --skill '*'
```

按提示选择你正在使用的客户端并更新已有项目。项目级安装不加 `-g`；手动安装按本页步骤替换完整 14 个目录。完成后新开对话，后续即可说“更新渡鸦”。

### Claude Code 插件手动更新

自然语言更新会走原生插件渠道，也可以在终端先更新市场，再更新插件：

```bash
claude plugin marketplace update duya-skills
```

```bash
claude plugin update duya@duya-skills
```

重启 Claude Code 后使用更新版本。

### 卸载

通用工具安装的全局版本，运行：

```bash
npx -y skills remove -g
```

在选择界面中只选择本页列出的渡鸦 14 个入口，并按提示选择客户端。当前项目安装则不加 `-g`。不要使用移除全部技能的 `--all`，它会扩大到渡鸦之外。

手动安装时，只移除这次安装的 `duya` 与对应 13 个 `duya-*` 文件夹。Claude Code 插件卸载使用：

```bash
claude plugin uninstall duya@duya-skills
```

各安装渠道分别管理自己的安装记录。这些卸载操作不负责删除你另行配置的 MCP、导出成稿或 `~/.duya/memory/` 中的个人记录。
